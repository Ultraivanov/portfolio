# Codex Flow — Project Workflow

Name: **Codex Flow**

This project follows the Codex Code Starter workflow in `.codex/`.

## Core files
- `.codex/PHASES.md` — phase + block status
- `.codex/blocks/<ID>.md` — block tasks + change plans
- `.codex/SNAPSHOT.md` — session snapshot
- `.codex/BACKLOG.md` — pending items
- `.codex/ARCHITECTURE.md` — architecture notes

## Core commands
- `init-phases`
- `init-block <ID>`
- `init-task`
- `start`
- `/fi`

Use this workflow for all new work going forward.
